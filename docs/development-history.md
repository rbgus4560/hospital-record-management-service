- FastAPI OCR 중계 및 이미지 입력 검증, 결과 원본 디버그 저장.
- 영수증 좌표를 기준으로 일정·금액 등 영역별 후보 추출.

- 선택 영수증 PDF 합치기·개별 PDF ZIP 구성.
- 2026-10-22: 초기 React 템플릿 README 보존 후 실제 구현 기준 포트폴리오 README·구성도 작성. 프런트 빌드·백엔드 구문·합성 파서 확인.

- 사용자 참고 이미지 기준 최소 화면 너비 1610px·레이아웃 높이 900px 유지. 작은 창은 축소/세로 재배치 대신 스크롤.
