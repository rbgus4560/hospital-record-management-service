# 개발 과정

기간 2주·개인 웹 과제는 사용자 확인. 정확한 단계별 발생일·실패 횟수와 개인 선택 배경은 미확인이다.

- 제공된 현재 코드: React 환자·문서·일정 화면과 메모리 상태 관리.
- FastAPI OCR 중계 및 이미지 입력 검증, 결과 원본 디버그 저장.
- 영수증 좌표를 기준으로 일정·금액 등 영역별 후보 추출.
- SVG 영역 확인·수정 후 일정 반영, 저장된 OCR JSON 재파싱 API.
- 선택 영수증 PDF 합치기·개별 PDF ZIP 구성.
- 2026-10-22: 초기 React 템플릿 README 보존 후 실제 구현 기준 포트폴리오 README·구성도 작성. 프런트 빌드·백엔드 구문·합성 파서 확인.

이 목록은 커밋으로 증명된 시간 순서가 아닌 현재 코드의 기능 구분이다. 과거 GitHub README의 Spring Boot·DB·LLM 계획과 현재 구현의 차이를 명확히 정리했다.


2026-10-23 소스 공개 준비: 실행 코드·정적 자산·패키지 선언과 빈 설정 예시만 선별했다. 비밀 환경 파일·의료 OCR 원본·로그·가상환경·node_modules·dist는 제외한다. 기존 문서 기록은 보존하며 크롤러 requirements 줄바꿈 수정·버전 고정, 실행 스크립트 경로 이식성과 Python 인자 지원, 병원 백엔드 requirements 추가 및 ignore 보완을 수행했다. 설치·외부 API·실사이트·운영 DB는 실행하지 않았다.
